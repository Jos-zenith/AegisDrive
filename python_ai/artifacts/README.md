# Generated analysis outputs

Run `py analyze_data.py` from this directory's parent (`python_ai`) to recreate
the audit and district-index outputs. Paths can be overridden with
`--sign-dataset`, `--csv-dir`, and `--output-dir`.

The detector has not been trained. `metrics.json` and `confusion_matrix.json`
explicitly record unavailable measurements as null rather than fabricating
results.
